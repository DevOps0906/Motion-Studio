# task-006 편집기 필수 입력 안내·페이지 주소 자동 제안 (명세)

## 1. 필수 입력 안내 (`components/WebsiteBuilder.tsx`, 필요 시 해당 입력 컴포넌트)
- 필수 항목(프로젝트 이름·핵심 문구·브랜드 소개, 그리고 서버 `lib/website.ts` 검증이 필수로 보는 항목)의 라벨에 `*` 필수 표시 + `aria-required`.
- 저장 시 빠진 항목을 **한 번에** 목록으로 안내(role="alert", 항목 이름 나열)하고 첫 빠진 입력에 포커스. 서버 요청은 보내지 않는다.
- 추가 페이지의 필수(페이지 이름·첫 화면 제목·버튼 문구)도 빠지면 "페이지 '<이름>': 첫 화면 제목" 식으로 함께 안내.
- 서버 검증 로직·오류 문구는 바꾸지 않는다(클라이언트 검사가 서버와 어긋나면 서버 기준).

## 2. 페이지 주소 자동 제안 (`components/WebsitePagesEditor.tsx`, `WebsiteBuilder.tsx` addPage)
- 주소가 아직 자동값(`new-page` 또는 `new-page-<n>`)인 페이지만, 페이지 이름을 바꾸면 주소를 이름에서 만든 값으로 바꾼다. 사용자가 주소를 직접 바꾼 뒤에는 자동 변경하지 않는다.
- 만드는 규칙(순수 함수, `lib/` 아래, 테스트 가능): 영문·숫자는 소문자 하이픈 형식으로. 한글 이름은 흔한 페이지 이름 사전(회사소개/소개→about, 서비스→services, 문의/상담→contact, 오시는 길/위치→location, 포트폴리오/작업→portfolio, 가격/요금→pricing, 자주 묻는 질문→faq, 후기→reviews, 블로그/소식→blog, 채용→careers, 공지→notice, 팀→team)에서 찾고, 없으면 자동값 유지 + "영문 주소를 입력하면 링크가 더 읽기 쉬워집니다" 안내.
- 중복이면 `-2`, `-3` 접미사. `index` 금지, 48자 제한, 기존 정규식 `^[a-z0-9]+(?:-[a-z0-9]+)*$` 충족.
