# task-002 웹사이트 섹션 종류·페이지별 이미지 확장 (명세)

- 결정: 팀장, 2026-11-01. 사용자 "계속 진행" 지시에 따라 최소 범위로 확정.
- 위험도: 보통 → 변경 후 codex-reviewer(code).

## 1. 범위
1. 섹션 종류 2개 추가: `testimonials`(고객 후기), `faq`(자주 묻는 질문). 기존 `about`·`services`·`contact`와 같이 표시 여부·순서를 페이지별로 편집한다.
   - 후기: 제목 + 항목 최대 6개(`quote` 필수, `name` 선택). 각 문장 최대 300자.
   - FAQ: 제목 + 항목 최대 8개(`question`·`answer` 필수). 각 최대 300자.
   - 새 섹션 기본값은 `enabled:false`(기존 사이트 모양 유지).
2. 페이지별 대표 이미지: 추가 페이지가 홈과 다른 `heroImageId`를 고를 수 있다(비우면 홈 이미지 상속). 미리보기·저장 미리보기·단일 HTML·ZIP 출력에 각 페이지 이미지가 반영된다.
3. 안내 문구 정정: `components/WebsiteProductionForm.tsx:24`의 "한 페이지 HTML 출력"·"다중 페이지는 별도 구축 협의"를 현재 구현(다중 페이지 편집·전체 사이트 ZIP)에 맞게 고친다.

## 2. 호환성 (필수)
- 저장된 기존 데이터(섹션 3개, 섹션 필드 없음, 페이지 content 없음)는 그대로 열리고 같은 모양으로 출력된다. 검증은 섹션 3개 또는 5개를 받아들이고, 빠진 새 섹션은 `enabled:false`로 채운다.
- 중복 섹션 id·모르는 id·한도 초과는 지금처럼 오류.

## 3. 범위 밖
- 갤러리(여러 이미지) 섹션, 페이지 주소 자동 생성, 필수 입력 안내 개선 → 후속 후보.

## 4. 완료 조건
- `npm run typecheck`, `npm test`, `npm run build` 통과.
- `scripts/test-websites.cjs`에 추가: 기존 3섹션 데이터 호환, 후기·FAQ 검증(한도·필수), 출력 HTML에 후기·FAQ가 이스케이프되어 들어감, 페이지별 이미지가 해당 페이지 출력에만 들어감.
