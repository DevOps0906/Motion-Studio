# task-009 운영자 전체 문의함 보기 (명세)

- 결정: 팀장, 2026-11-02. 사용자가 다음 작업으로 선택. 위험도 보통(운영자 전용 화면, API·권한 규칙은 task-008 그대로) → 변경 후 reviewer(code).
- 근거: tasks/task-008.md 10장 5·9항. API `GET /api/inquiries?owner=all`은 이미 있다(운영자만, 남의 행은 감사 로그).

## 1. 범위
- 문의함(`/websites/inquiries`, `components/WebsiteInquiriesInbox.tsx`)에 운영자일 때만 "내 문의 / 전체 계정" 토글을 보인다. 기본은 내 문의.
- 전체 보기에서는 각 문의에 소유 계정 표시(계정 이름 또는 이메일 앞부분 마스킹 `sk***@gmail.com`; 이메일 원문 노출 금지)와 웹사이트 이름을 보인다.
- 운영자가 남의 문의를 열면 읽음 처리는 하지 않는다(task-008: 운영자는 남의 자료 change 불가 → 읽음 버튼 숨김).
- 운영자 여부는 서버 컴포넌트에서 세션으로 판정해 prop으로 넘긴다(클라이언트 추측 금지). 운영자가 아니면 토글이 없고 `owner=all`을 보내지 않는다.
- 반응형 3구간(모바일 ~767 / 태블릿 768~1199 / 데스크톱 1200~)에서 토글과 목록이 깨지지 않는다.

## 2. 완료 조건
- typecheck·test·build 통과. 테스트: 비운영자 세션은 페이지에 토글 없음·`owner=all` 요청 시 API가 본인 것만(기존 동작), 운영자 전체 보기에서 남의 문의 포함·감사 로그 1줄, 소유 계정 표시가 이메일 원문이 아님.
- 범위 밖: 문의 검색·필터·내보내기.
