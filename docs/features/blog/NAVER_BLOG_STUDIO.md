# 홈페이지형 네이버 블로그 제작기

2026-10-30. 사용자 제공 가이드와 네이버 공식 도움말을 분석해 기존 Motion Studio에 별도 제작기로 추가한다. 웹사이트 제작기와 공유 미디어·메타데이터·레퍼런스 탐색을 재사용한다.

## 제품과 범위

Figma 디자인 → 배경/타이틀 PNG → 네이버 레이아웃 설정 → 투명 위젯·링크 적용 → PC/모바일 검수를 기본 제작 방식으로 삼는다. 이번 MVP는 코드 기반 SVG 시안과 Rust resvg PNG를 생성하며 Figma 자동 편집·계정 연결은 하지 않는다. 편집용 SVG는 패키지에 포함한다.

네이버는 자유로운 Next.js HTML/CSS/JavaScript 배포 환경이 아니다. 배경 이미지와 위젯을 기존 네이버 게시글·프로필·카테고리 영역과 조합한다. 계정 자동 설치·글 게시·외부 링크 자동 검수는 범위에서 제외한다. 배경의 콘텐츠 카드는 디자인이며 실제 최신 글을 자동으로 가져오는 기능이 아니다.

## 구현 흐름

`/blog-skins`: 브랜드·문구·소개·색상·로고·대표 이미지·메뉴 링크 입력 또는 홈페이지 정보 JSON 가져오기 → 기업형/개인 브랜딩/매거진 스타일 선택 → PNG 미리보기 → 프로젝트 저장·다시 열기 → 설치 ZIP 출력.

프로젝트는 `.local-data/blog-skins/`에 저장한다. 저장한 스킨이 사용하는 이미지·로고는 미디어에서 바로 삭제하지 못하도록 참조를 검사한다. 모든 제작기와 동일한 좌측 GNB·우측 콘텐츠 및 상단 레퍼런스 검색/필터를 사용한다.

| 산출물 | 제작 규격 | 상태 |
| --- | --- | --- |
| 배경 PNG·편집 SVG | 1920×900 | 제작 캔버스 예시, 네이버 고정 규격 아님 |
| 타이틀 PNG | 966×200 | 별도 업로드 자료, 실제 편집 설정에서 확인 |
| 투명 위젯 PNG | 170×100, 170×500 | 알파 보존 |
| 콘텐츠 썸네일 | 1200×630 | 디자인 산출물 |
| 모바일 커버 | 1080×1080 | PC 스킨과 별도로 활용 |
| 위젯 HTML·좌표 JSON/CSV | 메뉴 1~5개 | 계정에서 수동 등록·보정 |
| 메타데이터·설치 안내 | JSON·TXT | 다시 가져오기 가능 |

메뉴별 URL과 공개 위젯 이미지 URL을 입력한다. 공개 이미지 URL이 비어 있으면 `__TRANSPARENT_IMAGE_URL__` 자리표시자를 출력한다. PNG를 공개 HTTPS 이미지 주소로 업로드한 후 코드에서 교체해야 한다. data URL을 네이버가 허용한다고 가정하지 않는다.

좌표는 배경 캔버스 기준이며 실제 네이버 레이아웃 좌표와 동일하다고 보장하지 않는다. 위젯 Y와 가로 보정을 제공하고, 선택한 레이아웃·확대율·브라우저에서 클릭 위치를 확인해야 한다. 모바일은 PC 위젯 배치를 그대로 사용하지 않는다.

## 확인한 공식 기준과 출처

- [네이버 스킨 설정](https://help.naver.com/service/5593/contents/15269?lang=ko&osType=PC): 관리·꾸미기 설정에서 스킨과 레이아웃을 설정·적용한다.
- [위젯 직접 등록](https://help.naver.com/service/5593/contents/15275?lang=ko&osType=PC): 가로 170px, 세로 최대 600px, 최대 20개, 일부 HTML 태그 제한 및 등록 전 미리보기 안내. 이 제작기는 그중 최대 5개의 메뉴를 출력한다.
- 확인일: 2026-10-30. 실제 네이버 계정 적용은 수행하지 않았으며 설치 성공을 선언하지 않는다.
- [사용자가 지정한 Readray 자료](https://readray.ai/digest/11953181/15858062?noteVersionId=15233543)는 이 환경에서 내용을 읽지 못했다. 그 페이지나 언급된 영상 전체를 재현한 것으로 표시하지 않고 제공된 본문과 위 공식 자료를 기준으로 기획했다.

## resvg 적용과 검증

`lib/server/rasterize.ts`가 애플리케이션에서 생성한 SVG를 `@resvg/resvg-js` 2.6.2로 PNG로 변환한다. 텍스트는 XML 이스케이프하고 이미지는 검증된 공유 파일을 data URL로 포함한다. 원격 URL·임의 사용자 SVG를 읽는 일반 변환 API는 제공하지 않는다. 입력 길이·픽셀 크기·외부 참조를 제한하며 한글 시스템 폰트 결과는 OS별로 확인한다. 사진 크롭·JPEG 인코딩은 기존 Sharp 경로를 유지한다.

검증 범위: PNG 6종의 크기·투명 알파, XML/링크 입력 검증, 메뉴 좌표, 저장·재열기·이미지 참조, 실제 브라우저 미리보기·ZIP 다운로드와 모바일 가로 넘침. 네이버의 실제 위젯 적용·모바일 홈 검수는 별도 수동 단계다.

## 사업화 후속 가설

사용자가 제시한 가설을 보존한다: 템플릿 19,000~49,000원, 맞춤 제작 15만~50만원, SaaS 월 9,900~29,000원, 브랜딩 패키지 30만~100만원. 시장 검증 전 가정이며 현재 가격·수익을 보장하지 않는다. 실제 스킨 한 개의 계정 적용과 PC/모바일 검수를 먼저 마친 뒤 반복 제작·유료 수요·운영 비용을 확인한다.


### 블로그 주소·레퍼런스로 시작하기

블로그 스킨 제작기 상단에서 네이버 주소·레퍼런스URL로 문구·메뉴·스타일과 PNG를 자동 구성합니다. aside를 왼쪽/오른쪽에 선택할 수 있고 클릭 좌표와 설치 패키지에도 반영됩니다. AI 키·모델 미설정 시 규칙 기반 초안임을 표시합니다. 실제 AI 연결과 범위는 [자동기획 안내](BLOG_AUTOPLAN.md)를 참고하세요.
