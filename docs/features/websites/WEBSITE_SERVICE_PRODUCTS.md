## 제작 경험과 현재 구현

/websites에서 세 상품의 적합 고객·이유·가격 가설·공통 품질 목표·추가 구축 범위를 비교한다. 각 상품은 /websites/editor/basic, /business, /premium의 서로 다른 제작 브리프로 연결한다. 이전 intermediate/advanced 주소는 새 주소로 리다이렉트한다.

모든 브리프의 공통 질문은 브랜드, 업종, 대상 고객, 방문자의 목표 행동, 제공 가치다. BASIC은 메뉴·준비 자료·문의 동선을 추가한다. BUSINESS는 서비스별 고객 여정, 전환 지표, CMS 담당자, 문의 처리 흐름을 추가한다. PREMIUM은 아트디렉션, 스토리 순서, 영상·기존 모델 준비, 권한·승인, 업무 연동을 추가한다. 일정·예산·검토할 모듈도 기록한다.

기획 반영 버튼은 입력한 브랜드·목표·제공 가치를 편집기의 제목·헤드라인·소개·타깃에 적용한다. 기존에 편집한 헤드라인·소개는 덮어쓰지 않는다. 브리프는 기존 프로젝트 저장과 함께 서버에 보관되며 재열기·메타데이터 가져오기 때 유지된다. 기획서 JSON을 별도로 다운로드할 수 있다. 고객 비즈니스·예산·내부 운영 메모는 공개 HTML에 삽입하지 않는다.

현재 실제 출력 엔진은 세 상품 모두 한 페이지 HTML이다. 레이아웃·디자인 키트·섹션·대표 이미지를 편집할 수 있다. 상품별 다중 페이지·CMS·CRM·GSAP 스크롤·통계·AI·n8n·외부 배포를 선택만으로 자동 구축하지 않는다. 옵션 선택은 구축 요구사항이며 실행·결제·견적 확정·외부 전송을 발생시키지 않는다.
