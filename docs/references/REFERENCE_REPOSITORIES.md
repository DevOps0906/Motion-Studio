# 연관·참고 저장소

## Arch-Studio

- 저장소: [DevOps0906/Arch-Studio](https://github.com/DevOps0906/Arch-Studio)
- 관계: Motion Studio와 건축·공간 자료 및 파일 기반 제작 흐름에서 연관된 프로젝트입니다.
- 참고할 설계: 웹·데스크톱 공통 구조, 파일 가져오기·검증, 원본과 파생 에셋의 구분, 모델·메타데이터 관리입니다.
- 연계 방향: 외부에서 준비한 모델과 자료를 Motion Studio의 웹·3D·영상 제작에 활용하는 파일·메타데이터 전달 규격을 발전시킵니다.
- 현재 상태: 참고 관계를 문서화한 단계이며 저장소 간 자동 동기화·공유 DB·실행 시 API 의존성은 연결하지 않았습니다.

현재 Motion Studio의 구현 범위와 지원 형식은 [파일 기반 제작 기준](../architecture/IMPORT_WORKFLOW.md)을 우선합니다. Arch-Studio의 기능·진행률을 Motion Studio의 완료 항목으로 계산하지 않습니다. 새 연계를 구현할 때는 참고한 커밋과 파일, 라이선스, 입력·출력 규격을 기록합니다.

기존 비교 기록: [Arch-Studio README 고정 커밋](https://github.com/DevOps0906/Arch-Studio/blob/2692f317d5879f8faaca77faf973acdfc6a6a624/README.md). 이 문서는 해당 기록과 현재 프로젝트의 파일 기반 제작 기준을 바탕으로 관계를 정리하며, 참고 저장소 최신 구현을 새로 검증한 보고서는 아닙니다.
