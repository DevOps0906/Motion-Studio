## 문서 관리 기준

- 일반 제품 문서는 해당 분류 폴더에 추가하고 폴더 README에 링크를 등록합니다.
- 루트 README는 실행·기능 요약의 진입점으로 유지합니다. AGENTS.md는 도구가 찾을 수 있도록 루트에 유지합니다.
- 문서를 이동할 때 문서·이미지·코드 경로의 상대 링크도 함께 갱신합니다.
- 건축·3D 설계 문서에는 과거 확장안이 포함돼 있습니다. 현재 범위는 파일 기반 제작 기준과 구현 현황이 우선합니다.
