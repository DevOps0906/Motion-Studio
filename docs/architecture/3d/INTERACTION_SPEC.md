# 건축 인터랙션 명세 — 초안

상태: 건축 기능 미구현. 현재 /gallery의 사진 탐색과 구분한다.

| 기능 | R3F 첫 MVP | Unity 후속 | Unreal 후속 |
| --- | --- | --- | --- |
| 회전·줌·팬 | 마우스·터치·초기화 | 탐색 UI와 연결 | 스트리밍 입력 라우팅 |
| 층별 보기 | 전체·단일 층·분해 표시 | 층 이동·씬 상태 | 층별 가시성·공간 전환 |
| 객체 선택 | objectId로 강조·정보 패널 | 작품·설비 선택 | Actor 매핑·정보 UI |
| 재질 변경 | 허용된 PBR 프리셋 | 엔진 재질 프리셋 | Material Instance 프리셋 |
| 투어 | GSAP 카메라·정지·재개 | 이동·충돌·안내 | Sequencer·자유 탐색 |
| 내부 이동 | 후속, MVP는 외관 중심 | 첫 체험 범위 | 프리미엄 체험 범위 |

상태: loading, ready, selecting, touring, paused, failed. 투어 중 사용자 입력은 투어를 정지하고 제어권을 돌려준다. 정지·처음으로·전체 보기·선택 해제는 항상 찾을 수 있게 둔다.

모바일은 터치 회전·확대와 큰 선택 메뉴를 제공한다. 포인터 잠금·키보드 이동이 없는 기기에는 대체 조작을 제공한다. prefers-reduced-motion에서는 자동 투어를 기본 시작하지 않는다.

재질 변경·분해·카메라 상태는 시각화 설정이다. CAD 치수·원본 재질·원본 transform을 조용히 변경하지 않는다. 메타데이터나 재질이 없을 때는 대체 표시와 구체적인 오류를 제공한다.

검증: 객체·층 ID가 원본과 일치, 선택과 카메라 이동 충돌 없음, 투어 취소 가능, 자료 누락에도 UI 복구 가능. Unity·Unreal은 이동·문·충돌·입력·세션 종료를 추가 검증한다.
