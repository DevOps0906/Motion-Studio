# CAD 모델링 명세 — 초안

> 2026-10-30 범위 변경: 도면 생성·법규 판정·새 CAD 모델링은 현재 개발에서 제외합니다. Arch-Studio와 겹치는 부분은 참고하고 가져온 파일의 검증·미리보기·웹/3D/영상 제작을 진행합니다. 아래 기존 CAD 생성안보다 [파일 기반 제작 기준](../IMPORT_WORKFLOW.md)이 우선합니다.

상태: 기획 / 실제 CAD 생성 미실행. 상위 기준: ARCHITECTURAL_STUDIO_PLAN.md.

## 입력과 데모

- 입력: 도면·입면·이미지·용도·부지 치수·건물 치수·층고·방위·층별 구성·필수 요소.
- 데모 가정: 부지 20×15m, 건물 매스 16×10m, 3층, 층고 3.6m, 남측 커튼월, 파사드 기준 간격 1.2m.
- 부지와 건물 외곽을 구분한다. 데모 치수와 여유 공간은 설계 가정이며 실제 대지·이격·법규 승인값이 아니다.
- 건물 높이 10.8m는 층고 합계다. 지붕·파라펫·층 구조 상세는 별도 항목으로 명세한다.

## 단위·좌표

- 교환 메타데이터와 런타임의 길이 단위는 m. CAD 문서의 원본 단위와 변환 배율을 보존한다.
- CAD 예시 기준: X 동쪽, Y 북쪽, Z 위. 웹 기준: X 동쪽, Y 위, Z 남쪽.
- 이 CAD 기준의 웹 좌표 변환은 (x,y,z) → (x,z,-y). mm 원본이면 추가로 0.001 배율을 적용한다.
- 모든 어댑터에 이를 강제 복사하지 않는다. 소스 축·방위·좌표와 적용한 4×4 변환 행렬을 기록해 기준 큐브와 축 표시로 확인한다.

## 객체 계약

Site → Building → Floor → Structure/Slab/Facade/Opening/Interior. objectId·floorId·category·sourceRevision을 기록한다. 표시 이름은 편집 가능하지만 ID는 유지한다.

생성 순서: 대지·원점 → 건물 외곽 → 층 기준 → 슬래브·외피 → 개구부·패널 → 부품·내부 요소. 각 단계에서 저장하고 치수·객체 수를 확인한다.

## 수용 기준

층 수·높이·외곽·방위가 명세와 일치하고, 누락·중복·의도하지 않은 교차를 기록한다. 원본 재열기와 변환 후 치수 비교를 통과해야 한다. 허용 오차와 실제 건축 검수 책임은 CAD_VALIDATION.md에 따라 확정한다.
