# 미디어 파이프라인 적용 메모 (HyperFrames 비교)

작성일 2026-11-20. 상태: **제안**. 공용 기획 정본: `platform-docs:products/_platform-core/MEDIA_PIPELINE.md`. 코드·의존성은 바꾸지 않았다.

## 현황

| 항목 | 내용 | 근거 |
|---|---|---|
| 렌더 엔진 | Remotion 4.0.539 (`@remotion/bundler`, `@remotion/renderer`, `@remotion/captions` 등) | `package.json` |
| 첫 템플릿 | 사진 6~36장 + 로고 → 15초 유튜브 인트로 → 1080p MP4 | `README.md` |
| 스크립트 | `video:render`는 Remotion CLI로 PhotoWallIntro 렌더 | `package.json:10` |
| STT | 없음 | 전체 검색 결과 |

## 적용안

| ID | 내용 | 영향 | 선행 |
|---|---|---|---|
| M-1 | Remotion을 유지한다 | 없음 | 없음 |
| M-2 | 신규 템플릿 후보 1종을 HyperFrames로 비교 제작해 기록한다. 같은 미디어 기반을 두 런타임이 읽을 수 있는지가 핵심 | 신규 템플릿 | 스파이크 S2 |
| M-3 | 자막이 필요한 템플릿이 생기면 WhisperX 정렬 결과를 `@remotion/captions` 입력으로 쓰는 경로를 검토 | 자막 템플릿 | 스파이크 S1 |

## 검증 (개발 전)

| ID | 방법 | 합격 기준(제안) |
|---|---|---|
| S2 | 같은 15초 인트로를 두 런타임으로 제작 | 품질 동등, 공유 미디어 기반 재사용 가능 |
| S1 | 자막 템플릿 후보에 한해 한국어 정렬 확인 | 정렬 동작 |
| S3 | LICENSE 원문 확인 | 정책 충돌 없음 |

## 하지 않을 것

|---|---|
